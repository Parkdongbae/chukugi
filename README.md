# 측우기(測雨器) 3D

조선의 측우기를 3D로 보며 **설치 방법**과 **측정 방법**을 익히고, **서울 강수량 1778–2026**을 그래프로 살펴보는 교육용 웹앱입니다.

**바로 보기:** https://parkdongbae.github.io/chukugi/

## 탭

| 탭 | 내용 |
|---|---|
| 설치 방법 | 자리 고르기 → 바닥 다지기 → 측우대 놓기 → 윗면 홈 → 하단·중단·상단 잇기 → 주척 준비 (8단계, 3D 애니메이션) |
| 측정 방법 | 내린 비(2~300mm)를 정해 재생: 비가 고임 → 주척을 넣고 젖은 자국을 척·촌·푼으로 읽음 → 「雨水 深 ○寸○分」 기록. 반 잘라 속 보기, 넓이가 다른 그릇과 깊이 비교 |
| 강수량 자료 | 연 강수량(11년 이동 평균, 시대 평균), 월 평균 비교(조선 1778–1906 · 근대 1908–1990 · 평년 1991–2020), 해마다 가장 비가 많은 달, 249년 × 12달 열지도, 해를 고르면 12달 막대·순위, 세 시대 통계(평균·표준편차·변동계수·추세), 표로 보기. 모든 그래프 아래에 출처 표기 |
| 퀴즈 | 8문항 |

## 주요 결과 (서울)

- 비가 가장 많은 달: 세 시대 모두 **7월** (조선 358mm, 근대 370mm, 평년 414mm), 다음은 8월
- 연평균: 조선 1778–1906 **1,204mm**, 근대 1908–1990 **1,303mm**(전쟁 결측 3해 제외), 평년 1991–2020 **1,418mm**
- 가장 많은 해 1821년 2,576mm, 가장 적은 해 1901년 376mm. 가장 많은 달 1832년 7월 1,297mm

## 자료

- `data/Seoul_precipitation_1778-1907_Lee_etal_2024.xlsx` — Lee, Shin & Hong (2024), *Scientific Data* 11:566. 자료: [Zenodo doi:10.5281/zenodo.11076768](https://zenodo.org/records/11076768). 승정원일기·일성록에서 복원한 일 강수량(rrn, mm, 양력)
- `data/kma_seoul108_daily_utf8.csv` — [기상청 기상자료개방포털](https://data.kma.go.kr/cmmn/main.do) 서울(108) 일 강수량 1907.10.1–2026.11.7 (CP949 → UTF-8)
- 이음: 1907년 9월까지 조선 자료, 10월부터 기상청 자료. 행이 없는 날이 있는 달(1950.9–1952.8 일부)은 결측, 그 해 연 합계는 비움
- `tools/build_data.cjs`가 두 자료를 월 합계로 만들어 `src/data.js`를 생성

## 만들기

```
npm install
npm run data    # src/data.js 다시 만들기 (원자료가 바뀐 경우)
npm run build   # index.html (오프라인에서도 열림)
npm test        # 환산·통계·논문 값 재현 테스트 7개
```

three.js 0.160, esbuild. 그래프는 SVG로 직접 그립니다.
