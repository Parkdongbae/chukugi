# 측우기(測雨器) 3D

조선의 측우기를 3D로 보며 **설치 방법**과 **측정 방법**을 익히고, **서울 강수량 1778–2026**을 그래프로 살펴보는 교육용 웹앱입니다.

**바로 보기:** https://parkdongbae.github.io/chukugi/

## 메뉴 (v2)

번호 순서대로 배우고, 다 본 메뉴에는 ✓가 붙습니다(잠그지 않음). 카드마다 **쉬운 설명**이 먼저 나오고, 치수·근거·출처는 「더 알아보기」에 접혀 있습니다.

| 메뉴 | 내용 |
|---|---|
| ① 설치 | 자리 고르기 → 바닥 다지기 → 측우대 놓기 → 윗면 홈 → 하단·중단·상단 잇기 → 주척 준비 (8단계, 3D 애니메이션, 단계 점 · 큰 「이전/다음」 · 차례로 보기). 기록/추정/가정 딱지 |
| ② 측정 | 내린 비(2~300mm)를 정해 **재생**: 비가 고임 → 주척을 넣고 젖은 자국을 척·촌·푼으로 읽음 → 「雨水 深 ○寸○分」 기록. 비 오는 동안 하늘이 흐려지고 마당이 젖음. 보기 방법: 반 잘라 속 보기, 넓이가 다른 그릇과 깊이 비교, 장면 시간 |
| ② 주척 읽기 도전 | 무작위 비 3문제, 젖은 자국을 1푼(2mm) 눈금으로 읽어 척·촌·푼 입력, ±1푼이면 성공, 별 0~3 |
| ③ 강수량 자료 | **질문 카드 4장**(가장 많은 달 · 해마다 같을까 · 옛날과 지금 · 내가 고른 해), 한 번에 그래프 하나. 더 많은 그래프: 해마다 1위 달, 249년 × 12달 열지도, 세 시대 통계 전체 표, 표로 보기, 치수와 자료의 출처. 모든 그래프 아래 출처 표기. 그래프는 화면 폭에 맞춰 다시 그려 좁은 화면에서도 글자가 줄지 않음 |
| ④ 퀴즈 | 8문항(보기 순서 섞음), 결과 별 0~3, 틀린 문제 다시 풀기 |

상단 오른쪽: 🏅 **내 기록**(완료 표시 · 별 · 배지 7개) · ❔ **도움말**(첫 방문 때 3장) · ⚙ **설정**.

## 설정 (⚙)

글자 크기(보통/크게/아주 크게) · 화면 색(밝게/어둡게/고대비) · 설명 수준(쉬운 설명/자세히) · 그래픽 품질(자동/낮음/보통/높음) · 3D 이름표 · 소리(켬/끔, 크기) · 움직임 줄이기 · 기록 지우기. 설정과 기록은 이 기기의 브라우저에만 저장됩니다(`chukugi.settings.v1`, `chukugi.progress.v1`).

## 주요 결과 (서울)

- 비가 가장 많은 달: 세 시대 모두 **7월** (조선 358mm, 근대 370mm, 평년 414mm), 다음은 8월
- 연평균: 조선 1778–1906 **1,204mm**, 근대 1908–1990 **1,303mm**(전쟁 결측 3해 제외), 평년 1991–2020 **1,418mm**
- 가장 많은 해 1821년 2,576mm, 가장 적은 해 1901년 376mm. 가장 많은 달 1832년 7월 1,297mm

## 자료

- `data/Seoul_precipitation_1778-1907_Lee_etal_2024.xlsx` — Lee, Shin & Hong (2024), *Scientific Data* 11:566. 자료: [Zenodo doi:10.5281/zenodo.11076768](https://zenodo.org/records/11076768). 승정원일기·일성록에서 복원한 일 강수량(rrn, mm, 양력)
- `data/kma_seoul108_daily_utf8.csv` — [기상청 기상자료개방포털](https://data.kma.go.kr/cmmn/main.do) 서울(108) 일 강수량 1907.10.1–2026.11.7 (CP949 → UTF-8)
- 이음: 1907년 9월까지 조선 자료, 10월부터 기상청 자료. 행이 없는 날이 있는 달(1950.9–1952.8 일부)은 결측, 그 해 연 합계는 비움
- `tools/build_data.cjs`가 두 자료를 월 합계로 만들어 `src/data.js`를 생성

## 만들기

```
npm install
npm run data    # src/data.js 다시 만들기 (원자료가 바뀐 경우)
npm run build   # index.html 한 파일 (오프라인에서도 열림, 글꼴만 대체)
npm test        # 환산·통계·논문 값 재현·주척 읽기 판정·별·콘텐츠 테스트 15개
```

| 파일 | 역할 |
|---|---|
| `src/kit/*` | 신기전·측우기·거중기 세 앱 공통 키트(무대·설정·기록·효과음·화면 스타일). 앱 고유 내용 없음 |
| `src/sim.js` | 순수 규칙: 치수, 척·촌·푼 환산, 측정 장면, 강수량 통계, 주척 읽기 출제·판정, 별, 퀴즈·배지·질문 카드 데이터 |
| `src/model.js` | 3D 모형(마당 박석, 대리석 측우대와 판 홈, 청동 측우기 3단·명문, 주척 1푼 눈금, 물, 비, 전각·나무·담) |
| `src/charts.js` | 강수량 그래프(SVG 직접 그림) |
| `src/app.js` | 화면 흐름 |
| `src/template.html` | 화면 뼈대와 앱 전용 스타일 |

three.js 0.160, esbuild. 그래프는 SVG로 직접 그립니다. 효과음은 Web Audio로 합성합니다(음원 파일 없음).
