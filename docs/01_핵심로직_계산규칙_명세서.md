## 3. 강수량 → 수심 → 주척 읽기

### 3.1 수심 (`waterDepth(rainMm, rIn = GAUGE.rIn)`)

```
area  = π × rIn²            (mm²)       기본 rIn = 70 → 약 15,394mm²
vol   = rainMm × area       (mm³)
depth = vol / area          (= rainMm)  ← 그릇 넓이와 무관
ml    = vol / 1000
overflow = rainMm > GAUGE.h (320)
```

- 비 1mm가 측우기에 모이면 약 15.4mL. 60mm → 약 924mL, 300mm → 약 4,618mL.
- 입구와 몸통 굵기가 같은 원통일 때만 성립한다(측우기를 위아래 굵기가 같게 만든 까닭 — v1 문구 보존).
- UI의 내린 비 범위는 2~300mm(2mm 간격)라서 `overflow`는 UI에서 나타나지 않는다. 320mm 초과 안내 문구(「320mm가 넘으면 넘칩니다 — 큰비에는 하루에 여러 번 재고 비웠습니다」)는 코드에 있으므로 보존한다.

### 3.2 척·촌·푼 읽기 (`toChukPun(mm)`)

```
pun   = Math.round(mm / PUN)        // 반올림(0.5는 올림): 3mm → 1.5푼 → 2푼
cheok = floor(pun / 100)
chon  = floor((pun % 100) / 10)
p     = pun % 10
mm_read = pun × PUN                  // 읽은 값을 다시 mm로
```

| 규칙 | 내용 |
|---|---|
| 읽기 단위 | 1푼(2mm). 1푼 미만은 반올림되어 사라진다 → 측우기가 아주 적은 비(2mm 미만)를 재지 못한다는 v1 문구와 연결 |
| 0인 자리 | 한글·한자 모두 생략(`1척 2푼`, `一尺二分`). 모두 0이면 `0푼` / `無` |
| 한자 숫자 | `HAN = ['', '一' … '九']`(1~9). 척은 9까지만 안전(`HAN[10]`은 없음) — 최대 입력 320mm에서는 문제 없음 |
| 기록 문구 | `雨水 深 ${hj}` 예: `雨水 深 一寸五分` |
| 반올림 예 | 30mm → 15푼 → `1촌 5푼`(테스트), 204mm → 102푼 → `1척 2푼`(테스트), 0mm → `無`(테스트) |

기록 문구의 「寸」 앞 숫자는 한 자리(1~9)다. 10촌이 되면 1척으로 올림(`pun % 100` 방식).

## 4. 측정 장면 (`MEASURE`, `measureAt(t, total)`)

| 장면 key | 길이(초) | 물 높이 | 자 끝 높이(바닥 기준) | 젖은 자국 |
|---|---|---|---|---|
| `rain` | 8 | `total × (경과/8)` 직선으로 증가 | 없음(자는 옆에) | 없음 |
| `stop` | 2 | `total` | 없음 | 없음 |
| `ruler` | 4 | `total` | `440 → 0` mm, 완화곡선 | 끝에 닿으면(e > .99) `total` |
| `read` | 4 | `total` | `0 → 440` mm | `total` |
| `record` | 4 | `total` | 440 | `total` |
| `empty` | 3 | `total × (1 − e)` | (자 없음) | 없음 |

- 전체 25초(`MEASURE_TOTAL`). 440 = `GAUGE.h + 120`. 완화곡선 `smooth(u) = x²(3 − 2x)`, `x = clamp(u, 0, 1)`.
- 물 높이는 `Math.min(GAUGE.h, …)`로 320mm에서 자른다. 읽기 값(`reading`)은 자르지 않은 `total`로 계산한다.
- 읽기 값 표시는 `read`·`record`·`empty` 장면에서만(그 전에는 「—」).
- 기본 비는 60mm(`rainMm = 60`).

## 6. 주척 읽기 미션 판정 (확정, v2 신규)

| 항목 | 규칙 |
|---|---|
| 문제 수 | 3 |
| 출제 | 비 R은 **짝수 정수 mm**, 2~300(측정 슬라이더의 2mm 간격과 같음). 정답 푼 수 `truePun = toChukPun(R).pun = R / 2`로 정확히 떨어진다. 세 문제가 서로 겹치지 않게 구간별로 하나씩 뽑는다: [2, 60] · [62, 198] · [200, 300] (구간은 v2 신규. 셋째 문제에서 「1척」을 읽게 하려는 것) |
| 무작위 | `drawMission(rng = Math.random)` — 테스트에서 rng 주입 |
| 화면 | 같은 3D 측정 장면. 문제 중에는 물 깊이(mm)·받은 물(mL)·주척 읽기·기록 값을 가린다(답이 보이므로). 제출 후 공개 |
| 입력 | 척(0~1) · 촌(0~9) · 푼(0~9) 숫자 선택 3개 |
| 판정 | `ansPun = 척 × 100 + 촌 × 10 + 푼`, `diff = |ansPun − truePun|`, **`diff ≤ 1`이면 성공**(±1푼 = ±2mm) |
| 정확 | `diff = 0`이면 「정확」 표시 |
| 피드백 | 성공이면 정답 푼·mm 공개, 실패이면 「정답은 ○촌 ○푼(○○mm)」을 보여 주고 같은 장면을 한 번 더 볼 수 있다 |
| 한 문제 한 번 | 제출하면 잠금(퀴즈와 같음). 「다시 도전」은 새로 3문제를 뽑는다 |

미션 별(v2 신규): 3문제 중 성공 2개 이상 → ★1(클리어) · 3개 모두 성공 → ★★ · 3개 모두 성공이고 `diff = 0` 3개 → ★★★. 3문제 제출을 마치면 별이 0이어도 ② 측정의 ✓는 켠다(04 문서 §4).

주척 눈금 제약: v1의 주척 눈금은 5푼(10mm) 간격이다(`CHON / 2`마다 선, 5촌마다 긴 선). 푼 단위 읽기를 위해 v2에서 2mm 눈금을 추가한다(03 문서 §6, 05 문서 Should).

## 7. 강수량 자료 규칙

### 7.1 자료 구조와 이음

### 7.2 연 강수량·이동 평균

| 함수 | 규칙 |
|---|---|
| `annual(rows)` | 12달이 모두 있어야 합계. 한 달이라도 `null`이면 그 해 `v = null` |
| `movingAvg(series, w = 11)` | 반폭 `h = 5`. 각 해 `i`에서 `i−5 ~ i+5` 구간의 **`null이 아닌 값만** 평균. 그 개수가 `h + 1 = 6` 이상이어야 값이 있고 아니면 `null`. 양 끝은 구간이 잘려 비대칭 평균이 된다(v1 문구 「앞뒤 5년을 포함한 11년 평균(결측 해 제외)」) |
| 그래프 범위 | 연 계열 `A`는 `y ≤ 2025`(2026은 합계 없음). 이동 평균도 이 `A`로 계산하므로 1907년(이음 해, 합계 775.6mm)도 들어간다 |

현재 데이터에서는 이동 평균이 `null`인 해가 없다(1950~52년 한가운데도 유효 값 6개 이상).

### 7.3 시대와 통계

시대 구간 `ERAS`(양 끝 포함): 조선 1778~1906 · 근대 1908~1990 · 현재 평년 1991~2020. **1907년은 어느 시대 통계에도 넣지 않는다**(이음 해). 2021~2025년은 그래프에는 현재 색으로 보이지만 평년 통계에는 없다.

| 통계 | 식(`stats(series)`) |
|---|---|
| 해 수 n | `v ≠ null`인 해 |
| 평균 | 합 / n |
| 표준편차 | **표본** 표준편차: `√(Σ(v − 평균)² / (n − 1))` |
| 변동계수 | 표준편차 / 평균 (화면은 `(cv × 100).toFixed(0) + '%'`) |
| 추세 | 연도 `y`에 대한 `v`의 최소제곱 기울기 `slope = Σ(y−ȳ)(v−v̄) / Σ(y−ȳ)²`, 화면은 `slope10 = slope × 10`(10년마다 mm, `+/−`, 소수 없음) |
| 최다·최소 | 최댓값·최솟값 해 |
| 월 평균 `climatology(rows, y0, y1)` | 달마다 구간 해들의 값 중 `null`이 아닌 것의 평균(결측 달만 빼고 계속 평균) |
| 가장 비가 많은 달 `wettestMonth(row)` | 12달이 다 있어야 계산(`null`이면 `null`). 값이 같으면 앞선 달 |
| 1위 달 비율 `wettestCounts` | 시대 안에서 1위 달을 센 뒤 `해 수 / 센 해 전체 × 100`. 12달이 모두 있는 해만 |
| 여름 비율 `summerShare` | `(6월 + 7월 + 8월) / 합계`. 결측 달이 있거나 합계 0이면 `null` |

v1 현재 데이터 기준값(데이터를 다시 만들면 달라질 수 있으므로 **테스트 기준은 논문 값 허용 오차**로 둔다):

| 평균 | 1,204mm | 1,303mm | 1,418mm |
| 표준편차 / 변동계수 | 386 / 32% | 334 / 26% | 371 / 26% |
| 추세(10년마다) | −14mm | +23mm | −62mm |

### 7.4 해석상의 한계(그대로 표시)
- 측우기는 눈을 녹여 재지 않았다 → 겨울 값이 작다. 1푼(2mm) 미만 비는 재지 못한다. 조선 값이 조금 작을 수 있다(Lee 외 2024).
- 시대별 추세는 짧은 구간(특히 30해)에서 크게 흔들린다 — 「더 알아보기」에서만 보이고, 쉬운 설명에서는 추세를 단정하지 않는다(v2 신규 문구).
