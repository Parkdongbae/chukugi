## 3. 저장 방식 결정: 로컬 저장 vs 회원제

| 기준 | 기기 저장(`localStorage`) | 회원제(서버) |
|---|---|---|
| 도입 비용 | 낮음(코드만) | 서버·인증·운영 필요 |
| 개인정보 | 수집 없음 | 이름·이메일·학급 정보 → 아동 개인정보 대응 필요 |
| 교실 사용 | 공용 기기에서는 기록이 섞일 수 있음 | 개별 기록 가능 |
| 오프라인 | 가능 | 불가 |
| 배포 | GitHub Pages 정적 배포 그대로 | 별도 호스팅 |

**결정: 로컬 저장.** 세 앱 모두 로그인 없이 기기에만 저장한다. 교실에서 기기를 같이 쓰면 「내 기록 지우기」(설정)로 초기화한다. 서버가 필요해지는 요구(학급 통계, 학생별 제출)가 생기면 그때 별도 프로젝트로 분리한다.

저장 키 `chukugi.settings.v1`, `chukugi.progress.v1`(버전 접미사 `v1`은 구조가 바뀔 때만 올림). 앞으로 구조가 바뀌면 `…v2`를 새로 만들고 `v1` 값을 한 번 옮긴다.

## 4. 기술 검증 ① WebGL 성능·품질 4단계

신기전과 같은 4단계 선택(자동 + 3단계)을 쓴다. 값은 v2 신규 초안이며 실측 후 확정한다.

| 선택 | 그림자 맵 | 픽셀 비율 | 비 입자(v1 1,400) | 기타 |
|---|---|---|---|---|
| 낮음 | 없음(0) | 1 | 약 400 | 반사·안개 단순, 튀김 입자 없음 |
| 보통 | 2048 | 최대 1.5 | 1,400(v1 값) | 환경맵 128 |
| 높음 | 4096 | 최대 2(v1과 같음) | 약 2,800 | 환경맵 256, 물 파문·튀김 입자 |
| 자동 | 위 3단계 중 선택 | — | — | 아래 규칙 |

**세 앱의 공통 키트(`stage.js`의 `QUALITY`) 값을 따른다**: 그림자 0 / 2048 / 4096, 화소 비율 1 / 1.5 / 2. 위 표의 그림자 값은 이에 맞춰 고쳤다(「높음」은 4096). 비 입자 수(400 / 1,400 / 2,800)는 앱(`app.js`)에서 정하고, 움직임 줄이기에서는 절반.

**자동 규칙(v2 신규)**: 처음 3초간 평균 프레임 시간을 잰다. 33ms 초과(30fps 미만)가 이어지면 한 단계 낮추고, 16ms 이하가 이어지면 올린다(최대 「높음」). 사용자가 직접 고르면 자동은 끈다. 한 번 정한 값은 설정에 기록하지 않고 세션 동안만 쓴다.

| 검증 항목 | 합격선 |
|---|---|
| 보통, 내장 그래픽 노트북 | 30fps 이상(설치·측정 모두, 비 내리는 장면 포함) |
| 낮음, 보급형 태블릿 | 30fps 이상 |
| 비 장면에서 입자 갱신 비용 | 프레임당 GPU 업로드(`position.needsUpdate`) 1,400개 기준에서 끊김 없음 |
| 첫 화면까지 시간 | 576KB 기준 로컬 5초 이내(저사양 폰은 측정 후 기록) |
| 메뉴 ③ | 렌더 루프 정지(`if (tab === 'data') return`) → 그래프 탭에서 GPU 사용 0에 가깝게 |
| 메모리 | 메뉴를 20번 오가도 텍스처·지오메트리가 늘지 않음(`dispose`) |

## 5. 기술 검증 ② SVG 그래프의 작은 화면 대응

현재 그래프(`charts.js`)는 `viewBox 0 0 900 H`로 그려 CSS 폭에 맞춰 **축소**한다. 폭 375px(화면 약 343px 안)이면 배율이 약 0.38이라 `11px` 글자가 약 4.2px, 막대·눈금도 가늘어진다(00의 P4).

| 항목 | 대응(v2) |
|---|---|
| 폭에 맞춘 다시 그리기 | `ResizeObserver`로 컨테이너 폭을 읽고 `viewBox` 가로 `W`를 그 폭으로 두어 다시 그림 → **viewBox 1단위 = 화면 1px**이라 글자·선이 줄어들지 않음 |
| 최소 글자 | 화면 기준 12px 이상(눈금·범례·값 라벨) |
| 눈금 줄이기 | 폭 ≤ 480px: x축 눈금 연도 20년 → 40년, 월 라벨 12개 → 격월 + 7월, y축 눈금 5개 → 3개 |
| 월 막대 | 폭이 좁으면 세 시대 묶음 막대를 **시대 한 개씩 탭으로 전환**(범례를 탭으로 겸함)하거나 막대 폭 하한 6px |
| 열지도 | 249칸 × 12칸. 폭 343px이면 칸 폭 약 1.3px — 읽기 용도가 아니라 「띠 모양」 감상용으로 두고, 해 선택은 슬라이더와 ◀ ▶로. 칸 높이는 15px 이상 유지 |
| 툴팁 | `pointermove`뿐 아니라 `pointerdown`/탭으로 열고 바깥 탭으로 닫기. 툴팁이 화면 밖으로 나가지 않게 좌우 보정(v1은 190px 기준) |
| 터치 영역 | 그래프 위 눌러 해 고르기는 정확도가 낮음 → 슬라이더·버튼을 항상 같이 둠 |
| 접근성 | `role="img"` + `aria-label`(v1 유지), 「표로 보기」(v1 ⑤)가 같은 데이터를 글자로 제공 |

검증: 폭 320 / 375 / 768 / 1280px 스크린샷 4장씩 비교, 화면 글자 12px 미만 요소 0개(개발자 도구로 `getBoundingClientRect` 스캔).

| 위험 | 내용 | 대응 |
|---|---|---|

| 오디오 수 | 빗소리 + 효과음 동시 | 효과음은 한 번에 하나, 빗소리는 단일 노드 |
| 탭 전환 | 숨겨진 탭에서 오디오·렌더 | `visibilitychange`에서 정지 |

## 7. 기술 검증 ④ `localStorage`를 못 쓰는 환경

시크릿 모드, 저장소 차단, `file://`, 용량 초과에서 접근이나 쓰기가 예외를 던질 수 있다.

| 동작 | 규칙 |
|---|---|
| 읽기·쓰기 | 모두 `try/catch`로 감싼다 |
| 읽기 실패·JSON 오류 | 기본값을 쓰고, 망가진 값은 덮어쓰지 않고 무시 |
| 쓰기 실패 | 값은 메모리에 유지(그 세션에서는 설정·기록이 동작). 설정 창과 「내 기록」에 「이 기기에서는 저장되지 않아요(창을 닫으면 사라져요)」 한 줄 |
| 버전 | `version` 필드 확인. 모르는 버전이면 기본값 |
| 값 검증 | 설정 값이 허용 목록 밖이면 기본값으로 교체 |
