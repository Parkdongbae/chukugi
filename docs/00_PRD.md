## 1. 배경과 문제

v1은 `src/template.html`·`src/app.js` 기준으로 탭 4개(설치 방법 · 측정 방법 · 강수량 자료 · 퀴즈)로 이루어져 있다. 내용은 충실하지만 학생이 쓰기에는 다음 문제가 있다.

| # | v1의 문제 | 근거(v1 화면·코드) |
|---|---|---|
| P1 | 한 화면에 조작·정보가 너무 많다 | 측정 탭: 슬라이더 2개·버튼 2개·체크 2개와 읽을 값 4개, 「왜 깊이만 재면 될까?」 상자, 접힌 출처 상자가 한꺼번에 오른쪽에 쌓임 |
| P2 | 강수량 자료 탭에 그래프·표 7종이 한꺼번에 나온다 | 연 흐름, 월 평균, 해마다 1위 달, 열지도, 표로 보기(왼쪽 영역에 세로로 쌓임) + 해별 12달 막대, 세 시대 통계표(오른쪽). 무엇부터 봐야 하는지 질문이 없다 |
| P3 | 글자가 작고 빽빽하다 | `body` 14px, 설명 `.d` 13px, 보조 `.m` 12px, 출처 `.src` 11px, 그래프 글자 11px, 버튼 13px(높이 약 30px), 단계 버튼 12.5px |
| P4 | 작은 화면에서 그래프 글자가 읽히지 않는다 | SVG는 가로 900 고정 `viewBox`를 폭에 맞춰 줄임 → 폭 375px에서 11px 글자가 약 4.6px로 줄어듦 |
| P5 | 어디서부터 해야 할지 알 수 없다 | 탭 4개가 같은 무게로 나열, 번호·진행 표시·「다음」 없음. 설치 단계 버튼 8개가 항상 펼쳐져 있음 |
| P6 | 말이 어렵다 | 설치 설명에 「박석」「수평」「마디 이음매의 띠」, 측정 설명에 「부피 = h × A」가 풀이 없이 나옴 |
| P7 | 3D가 밋밋하다 | 단색 청동(`0x4a4740`, metalness .45), 점 무늬 돌 텍스처, CSS 그라데이션 배경(`#cv`), 톤매핑 없음, 비는 선분 1,400개 |
| P8 | 환경에 맞출 방법이 없다 | 글자 크기·그래픽 품질·소리 설정 없음. 다크 테마는 OS 설정만 따름(`prefers-color-scheme`) |
| P9 | 다시 올 이유가 없다 | 퀴즈는 맞힌 수만 보이고 별·기록·목표가 없음. 직접 해 보는 활동(주척 읽기)이 없음 |
| P10 | 오프라인에서 글꼴이 바뀐다 | Google Fonts `<link>`를 쓰므로 인터넷이 없으면 시스템 글꼴로 대체됨(05 문서) |

## 2. 목표와 비목표

**목표**
1. 초등 5학년~중학 2학년 학생이 **설명 없이 3분 안에** 설치 1단계를 보고 측정 장면 재생까지 간다.
2. 수업 한 차시(40~45분) 안에 「설치 → 측정 → 주척 읽기 → 강수량 자료 → 퀴즈」를 끝낼 수 있다(04 문서 §6).
3. 교실의 낮은 사양 노트북·태블릿에서도 끊기지 않는다(그래픽 품질 단계).
4. v1의 모든 사실·수치·근거 표시를 **그대로 보존**한다.
5. 강수량 자료를 「질문 하나 → 그래프 하나 → 한 줄 답」으로 읽게 한다.

**비목표(v2에서 하지 않음)**
- 회원 가입·서버 저장·학급 관리(→ 05 문서)
- 외부 3D 모델 파일(glTF)·음원 파일 도입 — 단일 HTML·오프라인 원칙 유지
- 새로운 강수량 자료 추가·다른 지점 자료(내용 범위는 v1과 같음)
- 외부 그래프 라이브러리 도입(그래프는 계속 SVG로 직접 그림)

## 3. 사용자

| 사용자 | 상황 | 필요한 것 |
|---|---|---|
| 학생 (초5~중2) | 교실 태블릿·노트북, 1인 1기기 또는 모둠 | 큰 글자, 쉬운 말, 다음에 할 일이 보이는 화면 |
| 교사 | 교실 TV·빔프로젝터로 시연 | 아주 큰 글자, 고대비, 소리 끄기, 출처 자료 |
| 일반 관람자 | 휴대전화로 링크를 열어 봄 | 세로 화면에서도 3D·그래프·설명이 함께 보임 |

## 4. 핵심 설계 원칙

신기전 PRD와 같은 6원칙을 쓴다.

1. **한 화면에 한 가지 일** — 3D 무대(또는 그래프) + 카드 한 장. 나머지는 접어 둔다.
2. **쉬운 설명 먼저, 자세한 것은 펼쳐서** — 「쉬운 설명」 한두 문장이 먼저, 치수·근거·전문 용어·통계는 「더 알아보기」.
3. **순서가 보인다** — 메뉴에 번호와 완료 표시(✓). 카드 아래에 항상 「다음」 버튼.
4. **기본값으로 바로 된다** — 측정은 아무것도 바꾸지 않고 「재생」만 눌러도 된다(기본 60mm — v1 값). 고급 보기는 접혀 있다.
5. **사실과 추정을 구분한다** — 기록 / 추정 / 가정 딱지(v1은 「가정」 딱지만 있음. 03 문서에서 체계화).
6. **설정은 한곳에** — ⚙ 설정 메뉴. 바꾸면 바로 반영, 기기에 저장.

측우기 앱에서 덧붙이는 원칙(v2 신규): **그래프는 한 번에 하나, 질문과 함께**.

## 5. 기능 요구사항

### 5.0 메뉴 구성 (v2 신규)

실제 코드(`app.js`의 `setTab`, `quizb`)를 보고 v1 탭 3개 + 퀴즈 버튼을 번호 메뉴 4개로 재구성했다.

| 번호 | 메뉴 | v1에서 오는 것 | 새로 생기는 것 |
|---|---|---|---|
| ① | 설치 | 설치 방법 탭 8단계(`INSTALL`) | 단계 점·큰 이전/다음, 쉬운 설명, 「전체 단계 보기」 접기 |
| ② | 측정 | 측정 방법 탭(`MEASURE` 6장면, 반 잘라 보기, 넓이 비교, 「왜 깊이만 재면 될까?」) | **주척 읽기 미션**, 「보기 방법」 접기 |
| ③ | 강수량 자료 | 강수량 자료 탭의 그래프·표 7종 | **질문 카드 4장** + 「더 알아보기」 |
| ④ | 퀴즈 | 퀴즈 8문항(`Q`) | 결과 별 0~3, 틀린 문제 다시 풀기 |

### 5.1 화면 뼈대 (F-SHELL)
- F-SHELL-1 상단 바: 제목 · 번호 붙은 메뉴 4개(① 설치 ② 측정 ③ 강수량 자료 ④ 퀴즈) · 오른쪽에 [🏅 내 기록] [❔ 도움말] [⚙ 설정].
- F-SHELL-2 본문: 왼쪽 3D 무대(③에서는 그래프 영역), 오른쪽 패널(너비 `min(24rem, 40vw)` — 키트 값; v1은 360px). 폭 900px 이하에서는 위 3D·그래프(화면 높이의 46% — 키트 `46dvh`) · 아래 패널. (v1의 분기점은 860px.)
- F-SHELL-3 무대 위 표시: 위쪽 가운데 제목 띠(v1 `#cap`), 오른쪽 위 확대·축소·처음 시점 버튼(v1 `#zoom`), 왼쪽 아래 조작 안내(v1 `#hint`).
- F-SHELL-4 처음 방문 시 3장짜리 도움말(무대 돌리기 · 메뉴 순서 · 설정 위치). 한 번 닫으면 다시 자동으로 열지 않음(키트 `help()`, `chukugi.help.v1`). ❔로 언제든 다시 보기.
- F-SHELL-5 본문 글자 16px 이상, 보조 글자 14px 이상, 누르는 곳은 높이 44px 이상. 그래프 안 글자는 **화면에 보이는 크기** 기준 12px 이상(§5.4).
- F-SHELL-6 키보드: Tab으로 모든 조작 가능, Esc로 창 닫기, ←/→로 설치 단계·질문 카드 이동(02 문서 §7).

### 5.2 ① 설치 (F-INSTALL)
- 8단계(자리 고르기 → 바닥 다지기 → 측우대 놓기 → 윗면 홈 → 하단 → 중단 → 상단 → 주척 준비). 카드에 단계 제목 · 쉬운 설명 · 「이전 / 다음」 큰 버튼 · 단계 점(●○○…).
- 「더 알아보기」: v1의 자세한 설명 전문, 기록/추정/가정 딱지, 치수 표.
- 「차례로 보기」(v1 `iPlay` 자동 재생, 단계당 3.2초), 단계 목록은 「전체 단계 보기」로 접어 둔다.
- 마지막 단계에서 「측정으로 가기」 버튼.

### 5.3 ② 측정 (F-MEASURE)
- 기본 조작 2개: **내린 비**(슬라이더 2~300mm, 2mm 간격, 기본 60mm) · 큰 **「재생」** 버튼. 장면은 비 내림 → 그침 → 주척 넣기 → 읽기 → 기록 → 비우기(25초).
- 결과: 큰 글씨로 「雨水 深 ○寸○分」 하나. 물 깊이(mm)·받은 물(mL)은 「자세한 값」 접기.
- 「보기 방법」 접기: 반 잘라 속 보기(기본 켬), 넓이가 다른 그릇과 비교, 장면 시간 막대.
- 「왜 깊이만 재면 될까?」는 쉬운 설명 한두 문장 + 「더 알아보기」(부피 = h × A).
- **주척 읽기 미션**(확정, v2 신규): 무작위 비 3문제, ±1푼 허용. 규칙은 [01 §6](01_핵심로직_계산규칙_명세서.md), 흐름은 [02](02_화면흐름도_와이어프레임.md), 보상은 [04](04_피드백_게이미피케이션_기획서.md).

### 5.4 ③ 강수량 자료 (F-DATA) — 질문 카드

v1은 그래프·표 7종을 한 번에 보였다. v2는 **질문 카드 4장**을 한 장씩 보여 준다. 각 카드 = 질문 한 줄 + 그래프 하나 + 한 줄 답 + 「더 알아보기」.

| 카드 | 질문 | 보이는 그래프 | 한 줄 답(자료에서 계산) |
|---|---|---|---|
| Q1 | 비가 가장 많이 오는 달은? | 월 평균 막대(v1 ②) | 세 시대 모두 7월(조선 358 · 근대 370 · 평년 414mm) |
| Q2 | 해마다 비의 양은 같을까? | 연 강수량 꺾은선 + 11년 이동 평균(v1 ①) | 크게 다름. 가장 많은 해 1821년 2,576mm, 가장 적은 해 1901년 376mm |
| Q3 | 옛날과 지금, 비의 양이 달라졌을까? | 세 시대 평균 큰 숫자 3개(v1 통계표의 평균 행) | 평균 1,204 → 1,303 → 1,418mm. 조선 값은 눈을 못 재서 작을 수 있음 |
| Q4 | 내가 고른 해는 어땠을까? | 고른 해의 12달 막대(v1 `yearCard`) + 해 고르기 | 그 해 연 합계와 가장 많은 달 |

- 「더 알아보기」(카드 안이 아니라 **카드 목록 아래 별도 묶음**): 해마다 「가장 비가 많은 달」 비율(v1 ③), 249년 × 12달 열지도(v1 ④), 세 시대 통계 전체 표(표준편차·변동계수·추세 포함), 표로 보기(해마다 월 강수량), 치수와 자료의 출처.
- 모든 그래프 아래 **출처 표기를 유지**한다(v1 `SRC`, `SRC_J`, `SRC_K`).
- 그래프는 컨테이너 폭에 맞춰 다시 그린다. 화면에 보이는 글자 12px 이상, 작은 화면(≤ 900px)에서는 눈금·범례 수를 줄인다(05 문서 §5). 툴팁은 탭으로도 열리고, 해 고르기는 ◀ ▶ 버튼과 슬라이더로도 된다.
- 이 메뉴에서는 v1처럼 3D 무대를 숨기고 렌더 루프를 멈춘다(`if (tab === 'data') return`) — 배터리 절약을 위해 유지.

### 5.5 ④ 퀴즈 (F-QUIZ)
- 8문항, 한 문제씩(v1 문항 그대로). 신기전과 같이 오른쪽 패널 카드 안에서 풀고(창 아님), 보기 순서는 볼 때마다 섞는다. 맞히면 즉시 풀이.
- 끝나면 별 0~3개(8문항 중 4개 이상 1개, 6개 이상 2개, 8개 3개)와 「틀린 문제 다시 풀기」.

### 5.6 설정 메뉴 (F-SET)

신기전과 **같은 8항목**이다.

| 항목 | 값 | 기본 | 설명 |
|---|---|---|---|
| 글자 크기 | 보통 / 크게 / 아주 크게 | 보통 | 전체 글자 100% / 115% / 130% |
| 화면 색 | 밝게 / 어둡게 / 고대비 | 밝게 | 고대비는 교실 TV·저시력용. v1의 어두운 테마 토큰을 이어 씀 |
| 설명 수준 | 쉬운 설명 / 자세히 | 쉬운 설명 | 「자세히」는 「더 알아보기」를 처음부터 펼침 |
| 그래픽 품질 | 자동 / 낮음 / 보통 / 높음 | 자동 | 그림자·해상도·비 입자 수(§6) |
| 3D 이름표 | 켬 / 끔 | 켬 | 무대 위 치수·부재 이름표(v1 `setTags`) |
| 소리 | 켬 / 끔 + 크기 | 켬, 60% | 효과음·빗소리 |
| 움직임 줄이기 | 켬 / 끔 | 기기 설정 따름 | 카메라 이동·빗줄기 흔들림·화면 전환 최소화 |
| 기록 지우기 | 버튼 | — | 진행 기록·배지 초기화(확인 후) |

- 저장: `localStorage`의 `chukugi.settings.v1`. 바꾸는 즉시 반영(새로 고침 없음). 값 키는 신기전과 같다(키트 `settings.js`: `text`, `theme`, `level`, `quality`, `labels`, `sound`, `volume`, `motion`).
- 「움직임 줄이기」 기본값은 `prefers-reduced-motion`을 따른다.

### 5.7 내 기록 (F-PROG)
- 메뉴별 완료 표시, 배지, 퀴즈 최고 별, 주척 읽기 별. `chukugi.progress.v1`에 저장(04 문서 §4).

## 6. 3D 모델링·렌더링 요구사항

모형은 코드로만 만든다(외부 파일 없음). 치수는 `sim.js`의 `GAUGE`·`STAND`를 그대로 쓴다(측우기 높이 320mm, 바깥 반지름 75mm, 안 반지름 70mm, 3단 / 측우대 453 × 455 × 303mm, 홈 반지름 80mm·깊이 43mm).

| 항목 | v1 (`model.js`·`app.js`) | v2 |
|---|---|---|
| 색·톤 | 톤매핑 없음, 기본 sRGB 출력 | ACES 톤매핑 + sRGB |
| 하늘·환경광 | CSS 그라데이션 `#cv`, 반구광 1.4 + 직사광 2.2 | 대기 산란 하늘(Sky) + PMREM 환경맵. **갠 날**(설치, 측정 기본) / **흐린 날**(비 내리는 동안)(v2 신규) |
| 그림자 | 2048, 기본 필터 | 부드러운 그림자(PCF Soft), 품질별 0 / 2048 / 4096(키트 `QUALITY`) |
| 땅(마당) | 14 × 14m 박석 그림 한 장 | 박석 마당 + 가장자리 흙·풀 질감, 안개로 원근. 비 올 때 젖어 어두워짐(v2 신규) |
| 측우기(청동) | 3단 회전체, 단색 `0x4a4740`, metalness .45 / roughness .5 | **금속(청동) PBR**: 환경맵 반사, 거칠기 변화(손때·녹청 얼룩 약하게), 마디 이음 띠 모따기, 명문 음각(요철) |
| 측우대(대리석) | 상자 + 점 무늬 그림 | **돌 질감**: 대리석 결 + 요철, 모서리 모따기, 윗면에 **실제로 판 홈**(지름 16cm·깊이 4.3cm, 가정값) |
| 박석(다진 바닥) | 화강암 점 무늬 | 화강암 질감 + 요철, 두께 있는 판 |
| 물 | 반투명 푸른 원통(opacity .72) | **물 표면**: 환경 반사, 가장자리 살짝 올라온 수면, 비 올 때 잔물결·파문 |
| 비 | 선분 1,400개 | **비 입자**: 길이·기울기, 품질별 개수, 땅·측우대 튀김, 측우기 입구에서 파문 |
| 주척 | 나무색 + 눈금 그림 | 나무결 + 눈금(푼 눈금 추가 — v2 신규), 젖은 자국이 어둡게 번짐 |
| 넓이 비교 그릇 | 유리 재질 원통 2개(반지름 35mm, 160mm) | 같음 + 유리 반사 |
| 둘레(자리 고르기) | 상자 건물 + 원뿔 지붕, 구 3개 나무 | 곡선 처마·기둥이 있는 건물, 잎 덩어리 나무, 담 |

- 성능 기준(신기전과 같음): 「보통」 품질에서 내장 그래픽 노트북 30fps 이상, 「낮음」에서 보급형 태블릿 30fps 이상.
- 「낮음」: 그림자 없음, 해상도 배율 1, 비 입자 적게. 「높음」: 그림자 2048, 해상도 배율 최대 2(v1 `Math.min(2, devicePixelRatio)`). 구체 입자 수는 05 문서의 실측 뒤 확정.
- 「움직임 줄이기」: 카메라 이동은 즉시 이동, 하늘 전환 없음, 비 입자 속도·밀도 감소.

## 7. 공통 키트 (세 앱 공용)

`src/kit/`의 파일은 세 저장소에 **같은 내용으로 복사**한다.

| 파일 | 역할 |
|---|---|
| `kit.css` | 색·글자 토큰, 화면 뼈대, 카드·버튼·접기·대화창 스타일, 테마 3종 |
| `settings.js` | 설정 저장·불러오기, 설정 창, 문서에 반영 |
| `progress.js` | 진행 기록·배지 저장, 「내 기록」 창 |
| `sfx.js` | 효과음(Web Audio 합성, 음원 파일 없음) |
| `stage.js` | 렌더러·하늘·땅·조명·품질 단계·카메라 이동·이름표 |
| `ui.js` | 도움말, 대화창, 알림(토스트), 접기 등 작은 도구 |

측우기 앱만 다른 것: 앱 ID, 메뉴 구성(§5.0), 강조색(물빛 `--ac #1f6f8b`, 어둡게 `#5cb8d6`, 고대비는 키트 노랑 — v2에서 신기전의 붉은색과 구분), 시대 3색(키트 색에 이음: 조선 `--c1 = --warn` · 근대 `--c3 = --ok` · 현재 `--c2 = --info`. 테마마다 함께 바뀜. v1 값은 `#b5612a` · `#1f9a8a` · `#2f6ea8`), 콘텐츠, 그래프 코드(`charts.js`), `sim.js`. 기존 `app.js`의 렌더러·시점·이름표 코드는 `stage.js` 호출로 바뀐다.
