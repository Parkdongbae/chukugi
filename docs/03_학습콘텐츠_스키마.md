# 학습 콘텐츠 스키마

> **목적**: 설치 단계, 측정 단계, 질문 카드(그래프), 퀴즈, 미션, 배지의 데이터 구조와 「쉬운 설명 / 자세히」 2단계 기준을 정한다.
> **이 문서가 답하는 질문**: 콘텐츠를 어떤 모양으로 저장하나? 쉬운 설명은 무엇이고 자세히는 무엇인가? v1 문장은 어디에 들어가나?
> **관련 문서**: [00 PRD](00_PRD.md) · [01 핵심 로직](01_핵심로직_계산규칙_명세서.md) · [02 화면 흐름](02_화면흐름도_와이어프레임.md) · [04 피드백](04_피드백_게이미피케이션_기획서.md) · [05 MVP·기술검증](05_MVP범위_기술검증.md)

**보존 원칙**: v1 문장(`INSTALL.d`, `MEASURE.cap`, 퀴즈 문항·풀이, 그래프 부제·출처)은 **한 글자도 바꾸지 않고** `detail`(자세히)에 넣는다. 새로 쓰는 것은 `easy`(쉬운 설명)뿐이며 「v2 신규」다. 쉬운 설명은 자세한 설명이 말한 사실만 쉽게 바꿔 말하고, 새 사실·수치를 더하지 않는다.

## 1. 쉬운 설명 / 자세히 2단계 기준

| 구분 | 쉬운 설명(`easy`) | 자세히(`detail`) |
|---|---|---|
| 길이 | 1~2문장, 한 문장 40자 안팎, 최대 90자 | 제한 없음(v1 문장 그대로) |
| 말 | 초등 5학년이 아는 말. 「박석」「수평」 같은 말은 풀어 쓴다 | 용어·치수·근거 그대로 |
| 수치 | 꼭 필요한 하나만(예: 32cm) | 모든 치수·출처 |
| 표시 | 카드에 항상 보임 | 「더 알아보기」 안. 설정 「자세히」이면 처음부터 펼침 |
| 딱지 | 없음 | 기록 / 추정 / 가정(정의는 [01 §2](01_핵심로직_계산규칙_명세서.md)) |
| 추정 문장 | 「~로 보여요」로 끝낸다(단정 금지) | v1 문장 그대로 |

## 2. 설치 단계 (`install`)

```js
{
  id: 'stand',            // v1 key: site|base|stand|hole|g1|g2|g3|ruler
  order: 3,               // 1~8. v1 title의 「3. 」 접두는 분리
  title: '측우대 놓기',    // v1 t에서 번호 제거
  easy: '…',              // v2 신규 (아래 §2.1)
  detail: '…',            // v1 d 전문
  view: 'near',           // 'site' | 'near' | 'gauge' (v1 VIEWS 키; 5단계부터 gauge)
  tags: [{ text, pos:[x,y,z], color? }],   // v1 setTags 목록
  facts: [{ label:'기록'|'추정'|'가정', text }],   // 딱지 제안 §2.2
  sources: ['한국민족문화대백과 …']
}
```

### 2.1 쉬운 설명 제안 문장 (8단계 전부, v2 신규)

| # | 제목 | 쉬운 설명(제안) | 담은 사실(v1 `d`) |
|---|---|---|---|
| 1 | 자리 고르기 | 건물과 나무에서 떨어진, 하늘이 트인 마당에 놓아요. 지붕이나 나뭇가지에서 떨어지는 물이 섞이면 안 되거든요. | 처마·나뭇가지 물, 바람 피함 / 서울은 관상감·창덕궁·경희궁 마당 |
| 2 | 바닥 다지기 | 땅을 평평하게 다지고 납작한 돌을 깔아요. 바닥이 기울면 측우기도 기울어요. | 박석, 측우대가 기울면 측우기도 기움 |
| 3 | 측우대 놓기 | 돌로 만든 받침대(측우대)를 수평으로 놓아요. 땅에서 튀는 물이 들어가지 않고, 늘 같은 높이에서 잴 수 있어요. | 대리석, 수평, 높이 30.3cm, 튀는 빗물, 같은 높이 |
| 4 | 윗면 홈 | 받침대 윗면에 동그란 홈을 파요. 측우기 아래쪽이 꼭 끼어서 바람에도 쓰러지지 않아요. | 홈, 밑동이 끼어 넘어지거나 기울지 않음 |
| 5 | 하단 넣기 | 측우기는 세 마디예요. 먼저 바닥이 막힌 맨 아래 마디를 홈에 끼워요. | 위·가운데·아래 세 마디, 바닥이 막힌 하단 |
| 6 | 중단 잇기 | 가운데 마디를 맞물려 올려요. 마디가 나뉘어 있으면 물을 비우고 씻기 쉬웠을 것으로 보여요. | 맞물려 올림, 까닭은 「~로 본다」(추정) |
| 7 | 상단 잇기 | 맨 위 마디까지 올리면 높이 32cm 통이 돼요. 세종 때 정한 크기(1척 5촌, 지름 7촌)와 거의 같아요. | 높이 32cm, 안지름 14cm, 세종 규격, 명문, 띠 |
| 8 | 주척 준비 | 깊이를 잴 자(주척)를 옆에 둬요. 1척은 약 20cm, 1촌은 2cm, 1푼은 2mm예요. | 주척 1척 ≈ 20cm, 1촌 2cm, 1푼 2mm |

글자 수는 모두 90자 이내(공백 포함). 7단계의 명문(「錦營 測雨器 …」)과 마디 띠 설명은 `detail`에만 둔다.

## 3. 측정 단계 (`measure`)

```js
{ key:'rain', dur:8, cap:'…', easy:'…', sky:'overcast' | 'clear' }   // v1: key, dur, cap
```

| key | 길이(초) | `cap`(v1 그대로, 제목 띠에 표시) | `easy`(v2 신규, 카드 안) |
|---|---|---|---|
| rain | 8 | 비가 내린다 — 측우기 입구로 들어온 빗물이 그대로 고인다 | 비가 내려요. 빗물이 측우기 안에 그대로 고여요. |
| stop | 2 | 비가 그쳤다(또는 정해진 시각) — 관상감 관원이 측우기로 간다 | 비가 그쳤어요. 관원이 측우기로 가요. |
| ruler | 4 | 주척(자)을 측우기 안에 똑바로 세워 넣는다 | 자(주척)를 똑바로 세워 넣어요. |
| read | 4 | 자를 꺼내 젖은 자국까지의 깊이를 척·촌·푼으로 읽는다 | 자를 꺼내서 젖은 곳까지의 깊이를 읽어요. |
| record | 4 | 「雨水 深 ○寸○分」으로 적어 보고한다 — 승정원일기·일성록에 남음 | 읽은 값을 「雨水 深 ○寸○分」으로 적어요. |
| empty | 3 | 물을 비우고 다음 비를 기다린다 | 물을 비우고 다음 비를 기다려요. |

- `sky`(v2 신규): `rain`·`stop`은 흐린 날, `ruler`·`read`·`record`는 반쯤 갬, `empty`는 갠 날로 천천히 바뀐다(「움직임 줄이기」에서는 바뀌지 않고 갠 날 고정).
- 내린 비 입력 `rainMm`: 2~300, 2 간격, 기본 60(v1).
- 「왜 깊이만 재면 될까?」 카드: `easy` = 「그릇이 넓든 좁든 고인 물의 깊이는 같아요. 그래서 깊이만 재면 돼요.」 / `detail` = v1 `sciencebox` 문장 전문(부피 = h × A … 눈을 녹여 재지 않았으므로 겨울 강수량은 적게 기록, Lee 외 2024).

## 4. 질문 카드 (`cards`) — 강수량 자료

```js
{
  id: 'q1', order: 1,
  question: '비가 가장 많이 오는 달은?',
  chart: 'month' | 'annual' | 'era' | 'year',   // 아래 §4.1
  answer: { easy: '세 시대 모두 {m}! ({a})', fill: 'computeQ1' },   // 자료에서 계산해 채움
  detail: '…',                                   // v1 그래프 부제·출처·한계
  source: ['SRC_J', 'SRC_K'],                    // charts.js의 출처 상수 이름
  needs: { x: '월', y: 'mm' }                    // 축 이름(글자 크게 보이도록)
}
```

### 4.1 카드 목록 (v1 그래프와 연결)

| id | 질문 | chart | 한 줄 답(easy, 자료에서 계산) | `detail`로 가는 v1 문장 |
|---|---|---|---|---|
| q1 | 비가 가장 많이 오는 달은? | `month` (v1 ②) | 세 시대 모두 7월! 조선 358 · 근대 370 · 현재 414mm | 「…7월이 가장 많고 8월이 뒤따릅니다(장마·여름 소나기)… 겨울 값 차이에는 측우기가 눈을 재지 못한 영향도 섞여 있습니다.」 + 출처 줄 |
| q2 | 해마다 비의 양은 같을까? | `annual` (v1 ①) | 많이 달라요. 가장 많은 해 1821년 2,576mm, 가장 적은 해 1901년 376mm. | 「가는 선 = 해마다 값 · 굵은 선 = 11년 이동 평균 · 점선 = 시대 평균…」, 6·25 전쟁 결측 띠, 「1907.10 근대 우량계로 바뀜」 선 |
| q3 | 옛날과 지금, 비의 양이 달라졌을까? | `era` (v1 통계표 평균 행) | 평균이 1,204 → 1,303 → 1,418mm. 다만 조선 값은 눈을 못 재서 조금 작을 수 있어요. | v1 `statCard` 설명 전문(눈과 1푼 미만 비를 재지 못함, 근대는 1950–1952년을 뺀 80해, 추세는 최소제곱 기울기) |
| q4 | 내가 고른 해는 어땠을까? | `year` (v1 `yearCard`) | `{y}년은 {연합계}mm. 가장 많은 달은 {m}월이에요.` (합계 없는 해는 「전쟁으로 빠진 달이 있어 합계를 비웠어요」) | v1 6개 읽을 값(평균 대비, 여름 비율, 순위, 측우기 높이로)과 해별 안내 문구 |

더 알아보기 묶음(카드 아님):

| id | v1 그래프 | 제목(v1) |
|---|---|---|
| more1 | ③ | 해마다 「가장 비가 많은 달」은 언제였나? |
| more2 | ④ | 249년 × 12달 열지도 |
| more3 | 통계표 전체 | 세 시대 비교 — 연 강수량 통계(평균·표준편차·변동계수·가장 많은/적은 해·추세·7월 평균) |
| more4 | ⑤ | 표로 보기 — 해마다 월 강수량(mm) |
| more5 | 출처 상자 | 치수와 자료의 출처 |

그래프 공통: 색은 시대 3색(조선 `--c1`, 근대 `--c3`, 현재 `--c2`) + 범례 글자를 항상 함께 쓰고, 막대·선 끝에 직접 이름을 붙인다(색만으로 구분하지 않기, v2 신규). 모든 그래프는 `role="img"`와 `aria-label`을 가진다(v1 유지).

## 5. 퀴즈 (`quiz`)

```js
{ id:'qz2', topic:'measure', q:'…', options:['…','…','…','…'], answer:1, explain:'…' }
```

v1 `Q` 8문항을 그대로 쓰고 `topic`(어느 메뉴 내용인지)을 붙인다(v2 신규). 풀이(`explain`)는 v1 문장이 이미 한두 문장이므로 `easy` 따로 두지 않는다.

| id | 질문(v1) | 정답 | topic(v2 신규) |
|---|---|---|---|
| qz1 | 측우기로 잰 값은 무엇인가? | 고인 빗물의 깊이 | measure |
| qz2 | 측우기 지름을 두 배로 키우면 같은 비에 물 깊이는? | 같다 | measure |
| qz3 | 측우대를 땅보다 높게 둔 까닭으로 가장 알맞은 것은? | 땅에서 튀는 물이 들어가지 않게 | install |
| qz4 | 기록 「雨水 深 二寸三分」은 몇 mm인가? (1푼 = 2mm) | 46mm | measure |
| qz5 | 서울에서 평균적으로 비가 가장 많은 달은? | 7월 | data |
| qz6 | 1778–1906년 서울 연평균 강수량에 가장 가까운 값은? | 약 1,200mm | data |
| qz7 | 조선 측우기 기록이 겨울 강수량을 작게 보이게 만든 까닭은? | 눈을 녹여 재지 않아서 | data |
| qz8 | 측우기 기록이 강수량 연구에서 특별한 까닭은? | 같은 곳에서 오랫동안 매일 잰 정량 기록이어서 | data |

보기 4개 문구·풀이는 v1 `Q`의 값 그대로(여기서는 줄임). 채점·별은 [01 §8](01_핵심로직_계산규칙_명세서.md).

## 6. 미션 (`mission`) — 주척 읽기 (v2 신규)

```js
{
  id: 'readRuler', menu: 'measure', count: 3, tolerancePun: 1,
  rainRange: [2, 300], rainStep: 2,
  bands: [[2, 60], [62, 198], [200, 300]],
  stars: { clear: '성공 2개 이상', star2: '성공 3개', star3: '성공 3개 + 정확 3개' },
  prompt: '비가 내렸어요. 주척의 젖은 자국을 읽어 보세요.',
  hint:   '가장 짧은 눈금 한 칸이 1푼(2mm), 조금 긴 눈금은 5푼, 긴 눈금은 1촌(20mm)이에요.',   // 2mm 눈금을 넣어 바꿈
  reveal: { ko, hj, mm }       // 제출 후 공개 (toChukPun 결과)
}
```

- 규칙·판정: [01 §6](01_핵심로직_계산규칙_명세서.md). 화면: [02 §2.3](02_화면흐름도_와이어프레임.md).
- 주척 눈금: v1은 10mm(5푼) 간격 선 + 5촌마다 긴 선. 푼 읽기를 위해 2mm 간격 짧은 선을 더한다(v2 신규, Should).
- 해설 문장(제출 후): 「정답은 ○촌 ○푼(○○mm)이에요. 1푼은 2mm니까 ○○mm ÷ 2 = ○○푼!」 — 계산 근거는 01 §1.

## 7. 배지 (`badges`)

```js

```

7개(v2 신규, 04 문서 §5에서 설명):

| id | 이름 | 얻는 방법 |
|---|---|---|
