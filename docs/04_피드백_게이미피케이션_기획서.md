# 피드백·게이미피케이션 기획서

> **목적**: 소리·시각 피드백, 진행 기록, 배지, 주척 읽기 미션, 한 차시 흐름을 정해 「다시 와 보고 싶은」 앱으로 만들되 학습을 방해하지 않게 한다.
> **이 문서가 답하는 질문**: 어떤 소리와 움직임을 언제 쓰나? 무엇을 기록하고 어떤 보상을 주나? 40~45분 수업은 어떻게 흐르나?
> **관련 문서**: [00 PRD](00_PRD.md) · [01 핵심 로직](01_핵심로직_계산규칙_명세서.md) · [02 화면 흐름](02_화면흐름도_와이어프레임.md) · [03 콘텐츠 스키마](03_학습콘텐츠_스키마.md) · [05 MVP·기술검증](05_MVP범위_기술검증.md)

v1에는 소리·진행 기록·보상이 없다(퀴즈는 맞힌 수만 표시). 이 문서의 값(음높이·길이·크기 등)은 **모두 v2 신규 초안**이며 05 문서의 기기 시험 뒤 조정한다. 효과음은 `src/kit/sfx.js`(Web Audio 합성, 음원 파일 없음), 기록은 `src/kit/progress.js`를 세 앱이 같이 쓴다.

## 1. 설계 원칙 — 과하지 않게

| # | 원칙 | 뜻 |
|---|---|---|
| G1 | 배움이 먼저 | 소리·움직임은 「지금 한 일이 됐다」를 알려 줄 때만 쓴다. 장식용 반복 없음 |
| G2 | 짧게, 작게 | 효과음 0.5초 이내(빗소리 제외). 기본 크기 60%, 겹쳐 울리지 않게 한 번에 하나(빗소리는 바탕) |
| G3 | 틀려도 벌 없음 | 오답은 부드러운 낮은 소리 + 풀이. 점수 깎기·시간 제한·목숨 없음 |
| G4 | 경쟁 없음 | 순위·타이머·다른 사람과 비교 없음. 기록은 내 기기에만 |
| G5 | 끌 수 있다 | 소리 끔, 움직임 줄이기, 배지 알림은 한 번에 한 개만 |
| G6 | 소리만으로 알리지 않는다 | 소리마다 글자·색·모양 신호를 함께 보인다(소리를 끈 교실 대비) |

## 2. 효과음 (Web Audio 합성)

모든 소리는 `OscillatorNode`·`noise`(AudioBuffer)·`GainNode`·`BiquadFilterNode`로 만든다. 음원 파일·외부 요청 없음. 마스터 크기는 설정 「소리」 값(기본 60%).

| 이름 | 언제 | 합성 방법(초안) | 길이 |
|---|---|---|---|
| `tap` 누름 | 모든 큰 버튼, 메뉴 | 사인파 880Hz, 빠르게 감쇠 | 40ms |
| `step` 단계 넘김 | 설치 「다음」·질문 카드 이동 | 삼각파 520Hz → 660Hz 짧은 상승 | 120ms |
| `place` 놓임 → 구현: 키트 `knock`(측우기 마디)·`thud`(바닥·측우대) | 설치에서 새 부재가 제자리에 내려앉을 때 | 짧은 노이즈를 저역 통과(700Hz)로 거르고 사인 180Hz 합침(돌·금속 「툭」) | 160ms |
| `rain` 빗소리 | 측정 `rain` 장면과 주척 읽기의 비 내리기 | 백색 잡음 → 대역 통과(3~6kHz) + 저역 통과, 잔잔한 크기 변화(LFO). 장면 동안 반복, 끝나면 1초에 걸쳐 작아짐. 내린 비가 많을수록 약간 커짐(최대 +6dB) | 장면 길이(8초) |
| `drip` 물 고이는 소리 | 물이 차는 동안(`rain`) | 사인 800~1600Hz를 무작위로 짧게 「똑」. 간격은 내린 비(mm)에 비례해 촘촘해짐. 물이 높아질수록 음높이를 살짝 낮춤 | 60ms씩 |
| `ruler` 자 넣기 → 구현: 키트 `whoosh` | 자가 측우기에 들어갈 때 | 사인 440Hz → 330Hz 미끄러짐 | 200ms |
| `correct` 정답 → 구현: 키트 `ok` | 퀴즈·주척 읽기 성공 | 사인 C5(523Hz) → E5(659Hz) 두 음 | 280ms |
| `wrong` 오답 → 구현: 키트 `no` | 퀴즈·주척 읽기 실패 | 삼각파 A3(220Hz) → F3(175Hz) 낮고 부드럽게 | 300ms |
| `star` 별 → 구현: 미션 결과에 키트 `badge`(별 1개 이상) / `step` | 결과 창에서 별이 하나씩 켜질 때 | 사인 C6(1047Hz) 반짝, 별마다 음 하나씩 올라감 | 150ms씩 |
| `badge` 배지 | 배지를 얻었을 때 | 사인 C5-E5-G5 아르페지오 | 450ms |

- **자동 재생 제한**: 브라우저는 사용자 입력 전에 소리를 막는다. 첫 번째 누름/터치 때 `AudioContext.resume()`을 부른다. 그 전에는 소리 없이 시각 신호만 낸다(05 문서 §6).
- 탭을 숨기면(`visibilitychange`) 빗소리를 멈춘다.
- 「소리 끔」이면 `AudioContext`를 만들지 않는다.

## 3. 시각 피드백

| 상황 | 신호 | 「움직임 줄이기」일 때 |
|---|---|---|
| 단계 넘김 | 카드가 옆으로 밀려 바뀜 + 3D에서 새 부재 둘레에 얇은 고리가 한 번 깜박(0.6초) | 즉시 바뀜, 고리 없음 |
| 부재 내려앉음 | v1의 `(1 − e)³` 애니메이션(0.35~0.6m 위에서 1.1초) 유지 | 즉시 제자리 |
| 물이 참 | 수면 위 파문 고리, 「물 깊이」 숫자 올라감(count-up) | 숫자만 갱신 |
| 주척 읽기 | 젖은 자국이 진해지며 선이 한 번 반짝, 읽은 값 글자가 올라옴 | 반짝임 없이 표시 |
| 정답 | 초록 테두리 + ✓ 아이콘 + 풀이(v1 `.ok` 색 `#3d7a4a`) | 같음(움직임 없음) |
| 오답 | 붉은 테두리 + ✕ 아이콘 + 정답 보기 표시(v1 `.no`) — 흔들림 없음 | 같음 |
| 별 | 별이 하나씩 켜짐(0.2초 간격) | 한 번에 표시 |
| 배지 | 화면 위에서 내려오는 알림(토스트) 4초, 「내 기록」으로 가는 버튼 | 알림 위치 고정, 서서히 나타남 없음 |
| 하늘 | 비 오는 동안 흐린 하늘로 서서히 바뀜 | 바뀌지 않고 갠 날 |

색만으로 알리지 않는다: 정답·오답에는 ✓ ✕ 기호와 글자(「정답!」「아쉬워요」 — v1 문구)를 함께 쓴다.

## 4. 진행 기록 구조

`localStorage` 키 `chukugi.progress.v1`(JSON). 쓰기 실패(저장 불가 환경)는 메모리에만 두고 기록 창에 「이 기기에서는 기록을 저장할 수 없어요」를 한 줄 보인다(05 문서 §7).

```json
{
  "version": 1,
  "done": { "install": false, "measure": false, "data": false, "quiz": false },
  "install": { "maxStep": 0 },
  "measure": { "playedToEnd": false, "compareUsed": false },
  "mission": { "readRuler": { "stars": 0, "bestCorrect": 0, "attempts": 0 } },
  "data": { "cardsOpened": ["q1"], "erasPicked": ["joseon"] },
  "quiz": { "bestCorrect": 0, "stars": 0, "attempts": 0 },
  "badges": { "groundwork": "2026-11-23T05:12:00Z" },
  "updatedAt": "2026-11-23T05:12:00Z"
}
```

| 메뉴 | 완료(✓) 조건 |
|---|---|
| ① 설치 | 8단계를 모두 한 번 이상 봄(`maxStep = 7`) |
| ② 측정 | 주척 읽기 3문제를 모두 제출함(성공 여부 무관, 별은 따로) |
| ③ 강수량 자료 | 질문 카드 4장을 모두 열어 봄 |
| ④ 퀴즈 | 8문항을 끝까지 풂 |

- 퀴즈·미션은 **최고 기록**만 올라가고 내려가지 않는다. 다시 해서 낮아져도 기록은 유지.
- 설정 「기록 지우기」는 `chukugi.progress.v1`만 지운다(설정은 유지).
- 개인 정보(이름·학교)는 저장하지 않는다.

## 5. 배지 7개

배지는 「칭찬 스티커」 수준으로 가볍게 한다. 정의(`id`, 조건)는 [03 §7](03_학습콘텐츠_스키마.md).

| 배지 | 조건 | 의도 |
|---|---|---|
| 터 닦은 이 | 설치 8단계 끝까지 | 설치 순서 이해 |
| 첫 빗물 | 측정 장면 한 번 완주 | 측정 과정 이해 |
| 눈금 읽기 | 주척 읽기 1문제 성공 | 척·촌·푼 읽기 |
| 정확한 관원 | 주척 읽기 3문제 모두 0푼 차이 | 정밀하게 읽기 |
| 깊이는 같다 | 넓이 비교를 켜고 재생 한 번 | 핵심 개념(깊이는 넓이와 무관) |
| 시간 여행자 | 조선·근대·현재의 해를 하나씩 골라 봄 | 자료 탐색 |
| 측우 박사 | 퀴즈 별 3개 | 종합 이해 |

- 한 번 얻으면 영구 보관. 얻는 순간 알림 한 번(`badge` 소리).
- 잠긴 배지는 「?」와 조건 한 줄(「내 기록」 창).

## 6. 주척 읽기 미션 (확정)

규칙·판정은 [01 §6](01_핵심로직_계산규칙_명세서.md)에 있다. 여기서는 학생이 겪는 흐름과 보상을 쓴다.

| 단계 | 화면 | 소리·움직임 |
|---|---|---|
| 1 문제 시작 | 「도전 1 / 3」, 안내 「비가 내렸어요. 주척의 젖은 자국을 읽어 보세요.」 | `tap` |
| 2 비 보기 | 「▶ 비 내리기」 → 8초 장면, 물 깊이 숫자 가림 | `rain` + `drip` |
| 3 읽기 | 주척이 들어갔다 나오며 젖은 자국이 보임. 촌 눈금과 푼 눈금(v2 신규, 2mm) | `ruler` |
| 4 입력 | 척 · 촌 · 푼 [−][+] | `tap` |
| 5 확인 | 정답 공개: 「정답은 ○촌 ○푼(○○mm) — 내 답과 ○푼 차이」 | 성공 `correct`, 실패 `wrong` |
| 6 결과 | 3문제 후 별 0~3과 「다시 도전」 | `star`, 조건을 채우면 `badge`(눈금 읽기·정확한 관원) |

- 실패해도 「한 번 더 장면 보기」 버튼이 있다(점수 영향 없음).
- 별·배지는 [01 §6](01_핵심로직_계산규칙_명세서.md)의 별 규칙과 [§5](#5-배지-7개)를 따른다.
- 틀린 이유 힌트(v2 신규): 오차가 1푼 초과이면 「1푼은 2mm, 가장 짧은 눈금 한 칸이 1푼이에요」를 한 줄 더 보인다.

## 7. 퀴즈 보상

- 8문항 중 4개 이상 ★1, 6개 이상 ★★, 8개 ★★★([01 §8](01_핵심로직_계산규칙_명세서.md)). 별이 켜질 때 `star`, 3개이면 「측우 박사」 배지.
- 결과 창: 별 · 「틀린 문제 다시 풀기」 · 「처음부터」 · 「내 기록」. 틀린 문제는 번호와 정답 한 줄을 보여 준다.
- 정답·오답 문구는 v1(「정답! 」「아쉬워요. 」 + 풀이)을 그대로 쓴다.

## 8. 한 차시(40~45분) 흐름 (v2 신규 제안)

| 시간 | 활동 | 메뉴 | 학생이 하는 일 | 교사 |
|---|---|---|---|---|
| 0~2분 | 들어가기 | 도움말 | 3장 도움말 보기, 설정에서 글자·소리 맞추기 | 소리 켜기/끄기 안내 |
| 2~10분 | 설치 | ① | 8단계를 「다음」으로 따라가며 「왜 거기에 두었을까?」 말해 보기 | 3·4단계(측우대·홈)에서 질문 |
| 10~17분 | 측정 보기 | ② | 60mm 재생 → 비를 바꿔 다시 재생, 넓이 비교 켜기 | 「깊이만 재도 되는 까닭」 |
| 17~24분 | 주척 읽기 | ② | 3문제 도전, 틀리면 장면 다시 보기 | 척·촌·푼 환산 확인 |
| 24~34분 | 강수량 자료 | ③ | 질문 카드 4장, Q4에서 자기 생일 해 고르기 | 조선과 지금 비교 토의 |
| 34~41분 | 퀴즈 | ④ | 8문항 풀기, 틀린 문제 다시 풀기 | 풀이 읽기 |
| 41~45분 | 정리 | 🏅 | 내 기록 확인 | 오늘 알게 된 것 한 줄 쓰기 |

한 차시에 모든 활동을 하지 않아도 된다. 번호 메뉴는 잠기지 않으므로 교사가 순서를 바꿀 수 있다.

## 9. 점검표

- [ ] 소리를 끄고도 모든 정답·오답·배지가 글자·기호로 구분된다.
- [ ] 첫 소리는 사용자가 한 번 누른 뒤에 난다(오류 로그 없음).
- [ ] 움직임 줄이기에서 카메라 이동·고리·흔들림이 모두 사라진다.
- [ ] 기록 지우기 뒤 ✓·별·배지가 모두 초기화된다.
- [ ] 배지 알림이 동시에 둘 이상 뜨지 않는다.
